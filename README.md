# 🛡️ Insurance Fraud Detection System

> ML-powered fraud detection for insurance claims - Built for the East African insurance sector

🚀 **Status:** In Development  
📊 **ML Model:** XGBoost Classifier (Training)  
⚡ **Backend:** FastAPI + PostgreSQL + Redis  
🎨 **Frontend:** Vanilla JavaScript + Chart.js  

## 🎯 Project Goal

Build a production-ready fraud detection system that can:
- Analyze insurance claims in real-time
- Provide risk scores (0-100)
- Flag suspicious patterns
- Save insurance companies $500K-$2M annually

## 📅 Development Timeline

- **Week 1:** Data preparation & ML model training
- **Week 2:** Model optimization & evaluation  
- **Week 3:** Backend API development
- **Week 4:** Frontend dashboard
- **Week 5:** Deployment & documentation
